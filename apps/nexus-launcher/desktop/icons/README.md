# Nexus application identity

The user-selected transparent Whale Station Master is the canonical Nexus icon. Preserve this identity in future releases unless explicitly asked to redesign it.

`whale-station-master-source.png` is the original approved image. `icon.png`, platform PNG sizes, ICO, ICNS, SVG image wrapper and `../../public/nexus-whale.png` are derived from it. Preserve alpha transparency and the opaque light belly/eyes.
