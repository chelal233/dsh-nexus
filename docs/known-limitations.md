# 已知限制与当前状态

[English](known-limitations.en.md)


本页记录用户可见边界，不再混入历史 reviewer 批次。旧记录完整保存在[归档](history/baselines/known-limitations.md)。

- v0.1.7：移动便携目录可能保留旧内置运行时路径，运行时保存可能被旧启动路径覆盖；本地源码已修复，未发布包不能按已修复使用。
- 声明兼容不保证插件行为或数据格式兼容；跨 Harness 版本降级可能看不到新格式会话。
- 浏览器无法直接提供所有 Electron 原生接口；第三方 Desktop 私有接口不属于全面兼容承诺。
- 内置运行时降低环境准备成本，不消除上游原生依赖对编译工具的要求。
- 未完成下载不会被当作可安装更新；便携包不能仅复制 EXE。更新是否全流程通过，需按具体构建验收。
- Windows/macOS x64/ARM64 是构建目标，不能据此声称所有平台与所有输入法、终端、权限组合均已真机通过。
- 系统签名、Apple 公证与校验清单签名是不同机制，以具体发布元数据为准。
- Harness/插件不是安全沙箱。快照不是全部用户数据的完整备份。

新增问题请同时标明影响版本、触发条件、临时处理、修复所在版本与验证层次；没有验证的结论不要标记“已解决”。
