# 已知限制与当前状态

[English](known-limitations.en.md)


本页记录用户可见边界，不再混入历史 reviewer 批次。旧记录完整保存在[归档](history/baselines/known-limitations.md)。

- v0.1.7：移动便携目录可能保留旧内置运行时路径，运行时保存可能被旧启动路径覆盖；已在 v0.1.8 修复，旧包需升级；显式外部路径仍须自行核对。
- 声明兼容不保证插件行为或数据格式兼容；跨 Harness 版本降级可能看不到新格式会话。
- v0.1.8 的 Web 模式在宿主就绪后，由启动器隐藏加载同一实例来检查客户端插件；启动器退出后不再维持该检查页面。缺少桥接报告、加载失败或超时时只报告“未验证”。本地真实 Electron 与受控插件树链路已验证，具体 Harness 发行版仍需单独验收；插件激活不等于所有会话、工具或界面操作可用。
- 浏览器无法直接提供所有 Electron 原生接口；第三方 Desktop 私有接口不属于全面兼容承诺。
- 受支持版本的运行依赖随 Nexus 提供；外部源码构建或新增第三方原生依赖仍可能需要自行准备编译工具。
- 未完成下载不会被当作可安装更新；便携包不能仅复制 EXE。更新是否全流程通过，需按具体构建验收。
- v0.1.8 的 Windows x64/ARM64、macOS x64/ARM64 和 Linux ARM64 已通过 CI 与安装包检查；不代表所有发行版、输入法、终端及权限组合均已真机通过。
- 系统签名、Apple 公证与校验清单签名是不同机制，以具体发布元数据为准。
- Harness/插件不是安全沙箱。快照不是全部用户数据的完整备份。

新增问题请同时标明影响版本、触发条件、临时处理、修复所在版本与验证层次；没有验证的结论不要标记“已解决”。

## 平台与离线边界

官方 Desktop 当前面向 Windows x64、macOS x64/ARM64，并要求兼容的受管 Harness 版本；Windows ARM64 与 Linux ARM64 仅提供 Web。Linux ARM64 提供 AppImage、DEB、RPM，包格式不代表所有发行版均兼容。完整离线迁移要求同系统、同架构，部分导出包不足以独立运行。Desktop 进程启动不代表内部插件和业务均已就绪。见[桌面端说明](harness-desktop.md)。

## v0.1.8 之后的待发布修复

已发布 Windows 包可能启动官方 Desktop 进程却隐藏窗口。当前源码已去除桌面进程的隐藏参数、统一托盘 Web 与工作台操作，并改为确认后下载更新；这些改动不在现有 GitHub v0.1.8 附件中，本地修复包须按构建编号识别。


未发布改动补充了 Desktop 启动观察和实际配置来源提示。支持的上游接口可确认启动期客户端激活；不支持或超时显示未验证。它不覆盖运行时业务正确性。Windows 单次本地测试中，无 Nexus 自检缓存的 Web 从点击到客户端可用约 67 秒，空 Desktop 运行时缓存及独立配置约 38.6 秒；两者配置不同，且未清除系统文件缓存，不能视为严格性能对比。以上 67 秒为上一轮优化的基线。本轮已对已验证的 Harness 0.1.6-alpha.2 去掉正常启动的隔离探针；同机同配置单次实测约 10.4 秒到客户端可用。仍不代表所有插件组合或系统冷缓存下的表现。
