# 手动验收清单

[English](acceptance.en.md)


记录版本、提交、构建编号、平台/架构、包类型和数据目录。每项记录实际结果、证据及未覆盖范围，不用旧报告代替当前构建验收。仅在独立测试数据上演练强关、迁移和恢复。

| 场景 | 验收标准 |
| --- | --- |
| 全新安装 / ZIP 解压 | 无开发工具环境下可打开；资源完整、Agent 身份正确 |
| 便携目录移动 | 内置运行时使用当前目录；外部固定路径保持不变；用户数据不被迁移 |
| 运行时保存 | 当前 Harness 不变；下次输入立即刷新；停止再启动使用新值，无需重启 Nexus |
| 参数、数据目录、profile | 保存/清空/冲突正确；下次输入与实际启动一致；当前记录不伪装成新值 |
| 版本准备与切换 | 准备不强制切换；停止与确认清晰；失败保留可理解状态 |
| 用户数据 | 测试前后核对 profile、会话和项目；自检不遗留用户可见测试 profile |
| 插件 | 市场选择和不安装路径都可用；声明冲突有说明；业务功能实际执行 |
| 通知 | 完成、失败、审批、回答；失焦/始终；Launcher 前台、任务后台；点击定位 |
| 中断恢复 | 在允许的测试点强关，重启后不盲目重放，不留未归属进程，不删业务数据 |
| Nexus 更新 | 自动/手动检测；后台下载；中断后重检；新版本取代旧下载；应用前明确中止 Harness |
| 系统交互 | Windows/macOS/Linux 文件选择、终端、剪贴板、输入法、缩放、托盘、休眠恢复 |
| 官方 Desktop | 支持目标显示入口，不支持目标隐藏；切模式前停止；准备取消和失败恢复保留数据 |
| 完整离线包 | 同系统同架构断网导出／导入；拒绝不匹配；保留 Unix 权限／链接和 macOS 签名应用结构 |
| 托盘 | Web／Desktop 控制、配置与维护入口；仅退出保留服务，停止全部成功后才退出 |
| 客户端启动 | 必需服务失败不能判成功；可选告警显示受限；无报告保持未验证；停用建议依据提供方证据 |
| 双语 | 中文/英文操作、错误、确认窗口、长文本和截图一致 |
| 卸载 | 按所选范围处理程序与数据；外部目录和未授权数据保留 |

CI smoke 不等于以上全部 PASS。发布报告只列真正执行过的项目。最新源代码中的修复需重新打包后才能完成安装包验收。
